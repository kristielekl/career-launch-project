# Routes

Place CareerLaunch Express routes and controller handlers here, grouped by feature
(for example, `timeline.js`). Register new routers in `../server.js`.

Read HTTP parameters and request bodies, call the appropriate service, and translate
results or errors into HTTP status codes and responses. Keep business validation,
ownership rules, and SQL out of route handlers: those belong in `../services/` and
`../repositories/`.

The instructor's appointment routes remain in `../server.js` as the starter baseline.
